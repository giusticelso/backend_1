🗺️ Anatomia de uma Classe UML

Um bloco UML é sempre desenhado dividido em 3 andares (topo, meio e base):

1. NOME DA CLASSE
2. Atributos (Características)
Ex: # nome, # vida
3. Métodos (Ações)
Ex: + atacar()
  • Símbolo + : Public (Todos acessam)
  • Símbolo - : Private (Ninguém acessa, trancado!)
  • Símbolo # : Protected (Herdável por filhos)

1. A Classe Base (O Molde)

Usamos o modificador protected para que as classes filhas enxerguem esses dados (o private bloqueia!).

class Personagem {
  protected nome: string;
  protected vida: number;

  constructor(nome: string) {
    this.nome = nome;
    this.vida = 100;
  }

  public atacar(): void {
    console.log("O personagem ataca com as mãos!");
  }
}

2. Herança (extends & super)

O Guerreiro herda tudo de Personagem. O super() é obrigatório para chamar o construtor do Pai!

class Guerreiro extends Personagem {
  public forca: number;

  constructor(nome: string, forca: number) {
    // 1º Passo: Chama o construtor do Pai
    super(nome);

    // 2º Passo: Inicializa o atributo próprio
    this.forca = forca;
  }
}

3. Polimorfismo (Override)

Subscrevemos o método atacar(). Múltiplas formas de agir com o mesmo comando!

class Mago extends Personagem {
  public mana: number = 50;

  // Nova forma de atacar no Mago
  public atacar(): void {
    if (this.mana >= 10) {
      console.log(`Bola de fogo! 🔥`);
      this.mana -= 10;
    }
  }
}

4. Enumerações (enum)

Dicionários imutáveis para evitar erros de digitação.

enum EstadoJogador {
  VIVO = "VIVO",
  MORTO = "MORTO",
  ENVENENADO = "ENVENENADO"
}

class Personagem {
  public estado: EstadoJogador;

  constructor(nome: string) {
    this.nome = nome;
    this.estado = EstadoJogador.VIVO;
  }
}
