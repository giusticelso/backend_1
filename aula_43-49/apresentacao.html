Associação, Agregação e Composição

Relacionamentos em TypeScript

Os objetos não existem isolados. Vamos aprender a ligar e agrupar classes no nosso jogo.

Conceito UML

🔗 Associação (O Básico)

Uma classe conhece a outra para interagir, mas não é dona dela. Ex: Um jogador manda mensagem para outro.

classDiagram class Jogador { + string nome + enviarMensagem(alvo: Jogador) } Jogador --> Jogador : interage
Prática TS

👨‍💻 Associação no Código

Na prática, basta receber a outra classe como um parâmetro em um método e usá-la temporariamente.

class Jogador {
  public nome: string;

  // Recebemos a classe alvo como parâmetro
  public enviarMensagem(alvo: Jogador, texto: string): void {
    console.log(`${this.nome} diz para ${alvo.nome}: ${texto}`);
  }
}
Conceito UML

🤍 Agregação (Dependência Fraca)

O Todo possui a Parte, mas a Parte sobrevive sem o Todo. Ex: Uma Guilda possui Personagens. Se a Guilda for deletada, os jogadores continuam vivos.

classDiagram class Guilda { + string nome + Personagem[] membros } class Personagem { + string nome } Guilda o-- Personagem : possui (0..*)
Prática TS

👨‍💻 Criando Arrays de Objetos

Em TypeScript, a Agregação é resolvida declarando um Array tipado com a classe que queremos guardar.

class Guilda {
  public nome: string;
  // Array vazio pronto para receber objetos Personagem
  public membros: Personagem[] = [];

  public recrutar(novoMembro: Personagem): void {
    this.membros.push(novoMembro);
  }
}
Conceito UML

🖤 Composição (Dependência Vital)

A Parte morre se o Todo for destruído. Ex: O Personagem e seu Inventário. Um inventário não fica voando sozinho pelo mapa sem dono.

classDiagram class Personagem { + string nome + Inventario mochila } class Inventario { + adicionar() } Personagem *-- Inventario : contém (1..1)
Prática TS

👨‍💻 Escondendo a Instância (Composição)

Na composição, o dono dá a luz à parte. Instanciamos a classe de dentro do próprio construtor da classe Pai.

class Personagem {
  public nome: string;
  public mochila: Inventario;

  constructor(nome: string) {
    this.nome = nome;
    // A mochila nasce e morre junto com o personagem!
    this.mochila = new Inventario();
  }
}
