O Problema da Tipagem Dinâmica

O V8 Engine tenta adivinhar o que você quer fazer na memória RAM. Chamamos isso de Coerção de Tipo Oculta, e causa falhas críticas.

let playerHP = "100"; // Texto vindo do Banco de Dados
let damage = 20;

// O JS tenta ajudar, e ao invés de subtrair, ele converte!
playerHP += damage;
// Resultado: O jogador fica com "10020" de vida. Está imortal!

TypeScript: O Contrato Rigoroso

A Tipagem Estática define o formato exato da variável. Tipos básicos:

  • number: Números (dinheiro, HP, nível).
  • string: Textos. Sempre entre aspas (`""`).
  • boolean: Valores lógicos ou de estado (true ou false). Ex: `isAlive`.
let hp: number = 100;
// Erro: Type 'string' is not assignable to type 'number'.
hp = "Kael"; ← BLOQUEADO! Nem chega no servidor.

Condicionais: Tomando Decisões

Usamos if, else if e else para criar ramificações baseadas em testes matemáticos.

if (xp >= 100) {
    console.log("🎉 Subiu de Nível!");
} else if (xp >= 90) {
    console.log("⚔️ Quase lá!");
} else {
    console.log("🛡️ Falta muito para upar.");
}

Switch Case

Ideal para quando uma variável possui opções exatas e limitadas (como Menus ou Classes de RPG).

let classeHeroi = "Mago";

switch (classeHeroi) {
    case "Guerreiro":
        hp = 200;
        break; // Pára a execução do switch aqui
    case "Mago":
        hp = 80;
        break;
    default:
        hp = 100; // Se não for nenhum dos anteriores
}

Cláusulas de Guarda (Clean Code)

No Back-End evitamos o "Hadouken Code". Isole e trate os erros antes, deixando a lógica principal livre na raiz.

// ❌ Ruim (If Aninhado)
if (hp > 0) {
    if (mana >= 10) {
        atacar();
    }
}
// ✅ Bom (Guard Clause)
if (hp <= 0) return;
if (mana < 10) return;

atacar(); // Caminho Feliz

Laços de Repetição: FOR

Usado quando SABEMOS EXATAMENTE o número de vezes que vamos iterar (Ex: Iterar 5 monstros, 10 itens).

// (1. Início ; 2. Condição de Parada ; 3. Passo)
for (let i = 1; i <= 5; i++) {
    console.log("Enfrentou monstro " + i);
}

O operador ++ significa "some ele mesmo com 1".

Laços de Repetição: WHILE

Usado quando NÃO SABEMOS quantas vezes vai repetir, dependendo apenas de uma condição se tornar falsa.

let hpChefe = 1000;

// "Enquanto o chefe tiver vida..."
while (hpChefe > 0) {
    console.log("Atacando Chefe!");
    hpChefe -= 150;
}
console.log("Chefe derrotado!");
