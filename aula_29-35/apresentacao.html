O Problema das Variáveis Soltas

Criar 1 monstro é fácil:

let monstroNome = "Goblin";
let monstroHp = 100;

E se precisarmos criar 50 monstros? Vamos ter 100 variáveis soltas pelo código. Precisamos de uma "Fábrica" que padronize isso: A Classe.

Professor Ensina

🧱 A Classe: Entidade

A Classe é o molde. Os Atributos são as características.

class Entidade {
  // Atributos
  nome: string;
  vida: number;

  // O Construtor: A função que roda quando o objeto nasce!
  constructor(nomeRecebido: string) {
    this.nome = nomeRecebido;
    this.vida = 100;
  }
}
Professor Ensina

🚀 Instanciando (Dando Vida)

A palavra new aperta o botão de ligar a fábrica.

let heroi = new Entidade("Arthur");
console.log(heroi.nome); // Output: Arthur

🔒 Encapsulamento: Modificadores

Temos que colocar fechaduras nos nossos atributos.

  • public: Porta aberta (Qualquer um edita).
  • private: Cadeado forte (Ninguém de fora encosta!).
  • protected: Cadeado familiar (Só classes filhas podem mexer).
Professor Ensina

🛡️ Getters e Setters

Se a vida está private, não conseguimos ver. Usamos Getters para olhar pelo buraco da fechadura.

class Entidade {
  private vida: number;

  // GETTER (Apenas Leitura)
  get lerVida(): number {
    return this.vida;
  }
}
Agora é com vocês!

  • Usem o private para trancar a cura.
  • Criem o Getter para ler o poder da poção.

Professor Ensina

🌳 Herança: O DRY

Queremos criar um Mago e um Guerreiro. Vamos repetir Nome e Vida de novo? Não!

Vamos Herdar tudo da Entidade usando extends.

Professor Ensina

🧙‍♂️ Construindo o Mago e o `super()`

class Mago extends Entidade {
  public mana: number;

  constructor(nome: string) {
    super(nome); // Liga para o construtor do PAI (Entidade) passar o RG!
    this.mana = 100;
  }
}
Agora é com vocês!

⚔️ O Guerreiro

Chegou a hora de criarmos o braço forte do grupo.

  • Criem a classe Guerreiro.
  • De quem ele vai herdar? (extends)
  • Em vez de mana, o Guerreiro usa Fúria (começa com zero).
  • Usem o super() no construtor.
Conclusão

🎭 Polimorfismo

Muitas Formas. O Pai tem um ataque genérico. O Mago herda esse método, mas sobrescreve (Override) usando Bola de Fogo. O Guerreiro sobrescreve usando Espadada.

O nome da ação é o mesmo (atacar()), mas cada classe tem a sua forma de agir!
