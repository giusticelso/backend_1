O Fim das Variáveis Soltas

Se o jogo tiver 50 monstros, e cada monstro tiver Nome, HP e Dano, você criaria 150 variáveis independentes? Isso é o caos.
Precisamos agrupar os dados.

Arrays (A Mochila)

Um Vetor/Lista guarda vários valores do mesmo tipo.
Perfeito para Inventários! O Índice (Endereço) sempre começa no ZERO.

let mochila: string[] = ["Poção", "Espada"];

// Acessando o primeiro item:
console.log(mochila[0]); // "Poção"

// Colocando e Tirando itens:
mochila.push("Chave"); // Guarda no final
mochila.pop(); // Arranca o último

Objetos Literais (A Ficha do RPG)

Objetos guardam características diferentes (chaves e valores) de uma única entidade.

let jogador = {
    nome: "Arthur",
    vida: 100,
    vivo: true
};

// Acessando propriedades com . (ponto)
console.log(jogador.nome);
jogador.vida = 80; // Levou dano!

Interfaces (O Contrato Blindado)

O TypeScript permite criar nossos próprios Tipos (Contratos).
Se um objeto for do tipo da Interface, ele não pode ter variáveis sobrando nem faltando.

interface Monstro {
    nome: string;
    hp: number;
}

let chefe: Monstro = {
    nome: "Troll",
    hp: 200
    // voa: true -> O TypeScript bloqueia! Erro!
};

Classes e POO

Uma Classe é a "Fábrica" que produz objetos.
O Objeto ganha "vida": ele guarda dados (Atributos) e tem Funções próprias (Métodos).

class Heroi {
    nome: string;
    constructor(nomeBatizado: string) {
        this.nome = nomeBatizado;
    }
    atacar() {
        console.log(this.nome + " Atacou!");
    }
}

let player = new Heroi("Conan");
player.atacar(); // Ação contida no próprio objeto!
