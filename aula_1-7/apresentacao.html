Apresentação e Setup do Ambiente Back-End

Usamos o tsx durante o desenvolvimento para pular a etapa manual visualmente.

Front-End vs Back-End (Jogos)

A arquitetura de sistemas cliente-servidor dividida por responsabilidades.

[ O CLIENTE (Front-End) ] [ O SERVIDOR (Back-End) ] - Renderiza os Gráficos 3D - Processa regras e dano verdadeiro - Toca as músicas e efeitos - Guarda o progresso no Banco de Dados - Lê teclado/mouse do jogador <========> - Impede trapaças (Cheat Engine) - Unity, Unreal, Navegador - Node.js, C#, Java, Python

O Motor: Node.js

Antes de escrevermos código, nossa máquina precisa aprender a falar JavaScript no servidor.

[ Instalação do Node.js ] 1. Acesse nodejs.org 2. Baixe a versão LTS (Long Term Support - Recomendada e Estável) 3. Instale com as configurações padrão 4. Abra o terminal e verifique: > node -v > npm -v

Ecossistema de Desenvolvimento

A base de ferramentas que usaremos neste semestre após instalar o Node.

1. Node.js (V8) -> O motor que instalamos, roda o JS no SO. 2. NPM -> Gerenciador de Pacotes (já vem com o Node). 3. TypeScript (TSC) -> Superset com tipagem forte (instalaremos via NPM). 4. VS Code -> Nosso Ambiente Integrado de Desenvolvimento (IDE).
