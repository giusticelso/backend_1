O Cliente: ArenaCraft

A ArenaCraft é uma plataforma competitiva (eSports) em ascensão que hospeda torneios de MMORPGs, gerencia matchmaking e mantém os rankings oficiais de milhares de jogadores.

O Problema

O aplicativo e o jogo 3D (Front-End) estão prontos. O Banco de Dados também. Porém, a ArenaCraft precisa de uma "ponte" segura para calcular os pontos das partidas antes de gravá-los. Se o próprio jogo calcular os pontos, hackers usarão Cheat Engine para falsificar vitórias.

Aetheria Engine API

Vocês foram contratados como Desenvolvedores Back-End Júnior.

Sua Missão

  • Construir a API Core do jogo usando TypeScript e Node.js.
  • Criar o "motor lógico" que recebe resultados e calcula o Ranking/ELO.
  • Proteger regras matemáticas para que o HP/XP nunca seja manipulado indevidamente (Encapsulamento).
  • Disponibilizar os dados para o site exibir o "Top 100" (Leaderboards) via rotas HTTP (JSON).

Como vamos construir isso? (Julho a Dezembro)

O desenvolvimento ocorrerá em 4 Fases incrementais.

  • Fase 1 (POO): Cérebro do Jogo. Sem internet ainda. Foco em algoritmos lógicos e criação das Classes de Herança na memória.
  • Fase 2 (Node.js & JSON): Instalação do ambiente de servidor e conversão dos objetos da memória para o formato universal JSON.
  • Fase 3 (Arena Web): Criação das rotas HTTP (EndPoints). A porta de entrada da API para verbos GET, POST, PUT e DELETE.
  • Fase 4 (Projeto Final): Refatoração de todo o código para a Arquitetura MVC (Model-View-Controller) com tratamento rigoroso de status HTTP.

O que vocês entregarão?

Ao final do semestre, o grupo será avaliado pelo seguinte "Dossiê":

Entregas Oficiais:

  1. Repositório Back-End: Código limpo hospedado no GitHub, operando lógicas em memória e padronizado em pastas MVC.
  2. Tratamento de Dados: Lógicas de proteção (Guard Clauses) para impedir dados inválidos de entrarem nas rotas.
  3. Dossiê da API: Um arquivo Collection exportado do Postman ou Insomnia com todas as requisições catalogadas para o Front-End consumir.
