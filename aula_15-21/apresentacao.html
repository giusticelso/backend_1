O Caos do "Copiar e Colar"

Na Engenharia de Software, seguimos a regra de Ouro: DRY (Don't Repeat Yourself).
Se você copia o mesmo código de cálculo de dano 10 vezes em lugares diferentes, e a regra mudar, você terá 10 dores de cabeça gigantes.

A solução? Encapsular a lógica em Funções.

O que é uma Função?

Pense nela como uma "Fábrica" que você constrói uma vez, e depois só aperta o botão para usá-la.
Dica de Clean Code: Nomes de funções sempre devem ser Verbos no infinitivo (Uma Ação).

// 1. Construindo a Máquina
function exibirMenu() {
    console.log("1 - Atacar");
    console.log("2 - Curar");
}

// 2. Apertando o botão!
exibirMenu();
exibirMenu(); // Use 1000x se quiser, sem sujar o código!

Parâmetros (A Matéria-Prima)

Fábricas precisam de ingredientes para processar. As Funções usam Parâmetros.
O TypeScript brilha aqui: Nós blindamos as "portas" da função exigindo tipos exatos.

// A porta "dano" SÓ ACEITA números.
function aplicarDano(dano: number, alvo: string) {
    console.log(`O alvo ${alvo} tomou ${dano} de dano.`);
}

// Injetando a matéria prima correta:
aplicarDano(50, "Goblin");

Return (O Produto Final)

Algumas funções só fazem efeitos visuais (void). Outras são processadores matemáticos que precisam devolver o resultado para o sistema usar! Usamos a palavra mágica return.

function calcularCritico(danoBase: number): number {
    let final = danoBase * 2;
    return final; // Cospe o resultado para fora (e desliga a função)
}

// O valor cuspido deve ser guardado em uma variável!
let meuDano = calcularCritico(20); // meuDano agora vale 40

Escopo Local

O que acontece dentro de uma função, fica dentro da função!
Variáveis nascem e morrem lá dentro, economizando Memória RAM.

function fazerMagia() {
    let segredo = "PoderOculto"; // Nasceu!
} // Morreu e foi removida da RAM!

// ERRO GRAVE! O mundo exterior não tem acesso ao interior da função.
console.log(segredo);

Arrow Functions (O Jeito Moderno)

Em projetos modernos, nós transformamos funções em Constantes de forma elegante.

/* Clássica (Anos 90) */
function curar(hp: number) {
    return hp + 50;
}
/* ES6+ Arrow Function */
const curar = (hp: number) => {
    return hp + 50;
};

Callbacks (Terceirizando Trabalho)

Uma Callback é uma função passada como parâmetro para outra função.
É como dizer: "Faça o seu trabalho e, quando terminar, rode essa outra função aqui".

const avisarMorte = () => {
    console.log("O Herói Caiu!");
};

// A função recebe o 'avisarMorte' como parâmetro 'callback'
const processarDano = (hp: number, callback: Function) => {
    if (hp <= 0) {
        callback(); ← Executando a função terceirizada!
    }
};

// Chamada da função passando a callback sem parênteses:
processarDano(0, avisarMorte);

IIFE (Função Imediata)

Immediately Invoked Function Expression.
Uma função que nasce e se executa imediatamente. Ótimo para isolar memória do boot do servidor.

// Envolvemos tudo em ( ) e colocamos um () no final para rodar
(const () => {
    let dbPassword = "super-secreta";
    console.log("Servidor Conectado!");
})();

// ERRO! O mundo externo não pode ver a senha!
console.log(dbPassword); ← Proteção perfeita da RAM!
